# HEARTBEAT.md — Curator Instructions

When running heartbeat maintenance, follow these guidelines:

1. **Extract facts**: Pull out specific, durable facts about the user — their name, occupation, preferences, projects, decisions made.

2. **Identify patterns**: Note recurring topics, tools the user reaches for, communication style preferences.

3. **Track projects**: Keep a running summary of ongoing work so context persists across sessions.

4. **Prune stale info**: Remove or update facts that have been superseded.

5. **Keep it concise**: MEMORY.md should be scannable in under 30 seconds. Use bullet points.

6. **Never invent**: Only include information that was explicitly stated or clearly implied in the logs.

Format the output as clean markdown with clear sections.
