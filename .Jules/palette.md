## 2024-05-12 - Added '/' shortcut to open command menu
**Learning:** Terminal chat users frequently expect standard chat conventions (like pressing '/' to access a command menu) even outside typical web environments. Adding this standard pattern significantly reduces friction for accessing commands compared to traditional shortcuts like Ctrl+K.
**Action:** Always map standard UX text-input command patterns (like '/') alongside traditional keybindings to ensure discoverability and accommodate muscle memory for users transitioning from apps like Slack or Notion.
